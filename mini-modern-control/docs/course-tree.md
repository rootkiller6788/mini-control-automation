# Prerequisite Dependency Tree — mini-modern-control

```
Modern Control Theory
├── Calculus (ODEs, integration)
│   └── Laplace transforms
├── Linear Algebra
│   ├── Matrix operations
│   ├── Eigenvalues/eigenvectors
│   ├── Rank, nullspace
│   └── Positive definiteness
├── Classical Control Theory
│   ├── Transfer functions
│   ├── Stability (Routh-Hurwitz)
│   └── PID control
├── Differential Equations
│   └── State-space representation
└── Probability & Statistics (for Kalman filter)
    └── Gaussian random variables
```

## Post-requisites (modules depending on this)
- Nonlinear control
- Adaptive control
- Robust control (H-infinity, mu-synthesis)
- Optimal control
- Model predictive control
- Estimation theory
