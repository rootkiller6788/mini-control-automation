# Course Alignment — mini-plc-automation

Nine-school curriculum mapping for PLC automation and industrial control.

| School | Course | Topics Covered |
|--------|--------|----------------|
| **MIT** | 6.302 Feedback Systems | PID control, anti-windup, Ziegler-Nichols tuning |
| **Stanford** | EE266 Digital Control | Discrete-time PID, sampling theory, anti-aliasing |
| **Berkeley** | EE128 Mechatronics | PLC programming, ladder logic, sequential control |
| **Illinois** | ECE 486 Control Systems | PID tuning, relay auto-tuning, process control |
| **Michigan** | EECS 460 Control Systems | FBD, state machines, industrial automation |
| **Georgia Tech** | ECE 4550 Industrial Controls | IEC 61131-3, ladder, FBD, ST, SFC |
| **TU Munich** | Automation Technology | PLC architecture, scan cycle, real-time constraints |
| **ETH Zurich** | 227-0690 Industrial Control | Safety PLC (IEC 61508), SIL, redundancy |
| **Tsinghua** | 自动化仪表与过程控制 | PLC scan cycle, PID on PLC, industrial communication |

## Key References
- IEC 61131-3 (2013): Programming Languages for PLCs
- IEC 61508 (2010): Functional Safety of E/E/PE Systems
- Liu & Layland (1973): Scheduling Algorithms for Multiprogramming
- Astrom & Hagglund (1984): Automatic Tuning of Simple Regulators
- Modbus over Serial Line v1.02 (2006)
